# Archived Documentation

These documents are retained for historical context: completed plans, redesign
notes, interim analyses, completed trackers, and old research notes.

They are not authoritative for current implementation behavior.
Agents must not treat archived docs as source-of-truth unless a task explicitly
cites one and asks for archaeology.

This directory has a local `.ignore` so default `rg` searches skip archived
Markdown. Use `rg -u docs/archive` only when a task explicitly needs history.

For current project state, start with:
- `docs/README.md`
- `docs/PROJECT_GOALS.md`
- `docs/PROTOCOL_V2.md`
- `docs/KNOWN_BUGS.md`
- `docs/ALPHA_RELEASE_GATE.md`
