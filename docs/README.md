# Documentation Map

Last updated: 2026-02-12

This folder now separates **active, authoritative docs** from **historical reference docs**.

## Active Docs (Authoritative)

- `docs/PROTOCOL_V2.md`: Current protocol behavior/spec aligned to implementation.
- `docs/KNOWN_BUGS.md`: Current open issues only.
- `docs/ALPHA_RELEASE_GATE.md`: Alpha readiness criteria and gate commands.
- `docs/GIT_WORKFLOW.md`: Commit/push/release workflow used in this repo.
- `docs/CHANGELOG.md`: Historical fixes and behavior changes.
- `docs/BUILD_SYSTEM.md`: Build instructions and targets.
- `docs/AUDIO_SYSTEM.md`: Audio I/O architecture.
- `docs/CONFIGURATION_SYSTEM.md`: Configuration model and runtime flow.
- `docs/GUI_ARCHITECTURE.md`: GUI structure and components.
- `docs/INVARIANTS.md`: Critical engineering invariants.
- `docs/CFO_CORRECTION_FLOW.md`: CFO handling pipeline details.
- `docs/CFO_PHASE_HARDENING_PLAN.md`: CFO hardening implementation and validation notes.
- `docs/ADDING_NEW_WAVEFORM.md`: Guide for adding waveform implementations.
- `docs/RESEARCH_DIRECTIONS.md`: Long-term R&D ideas (non-blocking).

## Archived Docs (Historical / Context)

Archived docs are kept for traceability and postmortem context but are **not** source-of-truth for current behavior.

- `docs/archive/`

Use archived docs for background only. For current behavior, use active docs above.
